# ドレミピアノ

5歳くらいの子どもやピアノ初心者が、スマホで直感的に遊べる小さなピアノアプリです。

## 入っているもの

- ド・レ・ミ／5音／ド〜高いドの切り替え
- 録音されたアコースティックグランドピアノ音源による再生
- A4=440Hzの12平均律に対応したド〜高いドの音階
- 鍵盤を押すと音が鳴る「ひいてみる」モード
- 音符カードが上から落ちる「音符をおす」モード
- 正しい鍵盤を押すとカードが星になって消える仕組み
- 「きらきら星」「かえるの合唱」「ドレミのぼうけん」の曲選択
- 曲を自動演奏で聴く「きいてみる」モード
- ぴったり押せたときのコンボ・星スコア
- 縦向き・横向きのスマホ画面に対応
- GitHub Pagesで公開できるPWA構成

## ファイルの役割

- `index.html`：画面の部品
- `style.css`：色、大きさ、スマホ対応
- `app.js`：鍵盤の音、ゲーム、曲データ
- `manifest.webmanifest`：ホーム画面に追加するための設定
- `sw.js`：一度開いた後も読み込みやすくする設定
- `icon.svg`：ホーム画面用アイコン

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。例：`doremi-piano`
2. このフォルダのファイルを、リポジトリの一番上にアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. ブランチを `main`、フォルダを `/ (root)` にして `Save` を押します。
6. 数分後に表示されるURLをスマホで開きます。
7. ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

曲を追加するときは、`app.js` の `SONGS` に音名を順番に書きます。現在の「きらきら星」と「かえるの合唱」は、パブリックドメイン／伝承曲として知られる旋律を、アプリ用に音名データとして登録しています。市販の編曲や録音を追加するときは、楽曲・編曲・音源の利用条件を確認してください。

音は、FluidR3_GMのアコースティックグランドピアノの録音サンプルを、GitHub Pagesから読み込んで再生します。音源はCC BY 3.0です。音源サーバーに接続できない場合は、A4=440Hzの12平均律で計算したピアノ風合成音に自動的に切り替わります。

音源：<https://github.com/gleitz/midi-js-soundfonts>

「きらきら星」は原曲がフランス民謡で、公開情報上パブリックドメインとして掲載されています。 「かえるの合唱」はドイツ民謡「Froschgesang」を原曲とする伝承曲です。特定サイトの楽譜画像や市販の録音はコピーせず、アプリ内には旋律を音名データとして登録しています。参考：<https://enc.piano.or.jp/musics/83008>、<https://kodomomusiq.com/score05-kaeru/>。商用公開や別の編曲を追加する場合は、利用条件を個別に確認してください。
