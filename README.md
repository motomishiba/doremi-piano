# ドレミピアノ

5歳くらいの子どもやピアノ初心者が、スマホで直感的に遊べる小さなピアノアプリです。

## 入っているもの

- ド・レ・ミ／5音／ド〜高いドの切り替え
- A4=440Hzの12平均律で計算した正確な音高
- 鍵盤を押すと音が鳴る「ひいてみる」モード
- 音符カードが上から落ちる「音符をおす」モード
- 正しい鍵盤を押すとカードが星になって消える仕組み
- 「きらきら星」「かえるのうた」「ドレミのぼうけん」の曲選択
- 曲を自動演奏で聴く「きいてみる」モード
- ぴったり押せたときのコンボ・星スコア
- 縦向き・横向きのスマホ画面に対応
- GitHub Pagesで公開できるPWA構成

## ファイルの役割

- `index.html`：画面の部品
- `style.css`：色、大きさ、スマホ対応
- `app.js`：鍵盤の音、ゲーム、曲データ
- `manifest.webmanifest`：ホーム画面に追加するための設定
- `sw.js`：一度開いた後も読み込みやすくする設定
- `icon.svg`：ホーム画面用アイコン

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。例：`doremi-piano`
2. このフォルダのファイルを、リポジトリの一番上にアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. ブランチを `main`、フォルダを `/ (root)` にして `Save` を押します。
6. 数分後に表示されるURLをスマホで開きます。
7. ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

曲を追加するときは、`app.js` の `SONGS` に音名を順番に書きます。公開する曲は、楽曲・編曲・音源の利用条件を確認してください。

音高は標準的なピアノの基準音 A4=440Hz の12平均律で計算しています。現在の音色は、外部音源を使わずブラウザで作る「ピアノ風の合成音」です。本物のピアノ録音音源にする場合は、別途サンプル音源を追加します。
